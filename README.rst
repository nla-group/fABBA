fABBA: symbolic approximation of time series
============================================

The maintained README is ``README.md`` in this repository (also used for PyPI
package metadata). See https://github.com/nla-group/fABBA and the full guide at
https://fabba.readthedocs.io/.

Install with ``python -m pip install fABBA``. The self-contained examples under
``example/`` demonstrate symbolization, reconstruction, codebook export,
parameter sweeps and a shared-codebook application.
